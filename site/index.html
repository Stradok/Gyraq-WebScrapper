Two ways to use it

  • Run it on this computer (Windows, macOS, Linux). Scrapes from your machine and uses Ollama for AI pitches. The first launch takes a few minutes to set up.
  • Monitor a server (every platform, including Android). A window onto a Gyraq already running elsewhere. Enter its address and sign in with its PIN.

First-launch notes

  • Windows. If you see “Windows protected your PC”, choose More info → Run anyway.
  • macOS. If it says the developer can’t be verified, right-click the app, choose Open, then confirm. Once is enough.
  • Linux. sudo apt install ./Gyraq-Lead-Scraper-*.deb, or make the AppImage executable and run it.
  • Android. Open the downloaded file and allow “install unknown apps” for your browser when asked.
  • For AI pitches and the WhatsApp bot, install Ollama on the machine running the scraper.
