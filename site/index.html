Two ways to use it

  • Run it on this computer (Windows / macOS / Linux): the app scrapes from your machine and uses Ollama here for AI pitches. First launch sets up what it needs and takes a few minutes.
  • Monitor a server (all platforms, including Android): a window onto a Gyraq that's already running on another machine. Enter its address and sign in with its PIN.

First-launch notes

  • Windows: if you see "Windows protected your PC", click More info → Run anyway.
  • macOS: if it says the developer can't be verified, right-click the app, choose Open, then confirm. Once is enough.
  • Linux: sudo apt install ./Gyraq-Lead-Scraper-*.deb, or make the AppImage executable and run it.
  • Android: open the downloaded file and allow "install unknown apps" for your browser when asked.
  • For AI pitches and the WhatsApp bot, install Ollama on the machine running the scraper.
